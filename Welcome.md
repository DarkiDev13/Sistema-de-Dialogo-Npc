# Sistema De Dialogo NPC #

## Documentación Sobre el Sistema

** Sistema de Dialogo con NPC. Este Sistema está pensado para una mejora en las experiencias de los juegos
dentro de la Plataforma Roblox Studio, Sin duda en nuestros juegos llega un momento donde quisieramos
que el jugador pueda interactuar con algo "TANGIBLE" dentro de nuestra experiencia. Les presentó
mi Sistema de Dialogo Para NPCS. Un Sistema Volátil que permite a los Developers Asignar Misiones
mediante este método de una manera más dinámica**

**
Archivos .lua:
DiálogoUI: Local script pensado para manejar el UI & GUI del Usuario y Mandar respuesta del Diálogo.
NpcInteraction: Server Script encargado de la lógica en el  servidor y detección al interactuar con un NPC.
Npcs: Carpeta donde se guardarán los modelos de los NPC.
Dialogando: RemoteFunction que se permitirán la comunicación de servidor a cliente.
Data: ModuleScript encargado de ALMACENAR los Dialogos en formato string, Numeros, Precios, Etc.
GUIFX: ModuleScript permitirá mediante funciones mostrar el diálogo con estilo TypeWriter.
**
